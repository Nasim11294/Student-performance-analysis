## 🎓 Project Details

**Let's Progress – Student Performance Analysis System** is a web-based academic performance analysis system developed as an MCA Major Project.

The system provides separate access for Admin, Staff, and Student users and helps manage and analyze student academic performance.

## 🚀 Key Features

### Admin
- Manage students
- Manage staff
- Manage subjects
- Manage marks
- Manage academic data

### Staff
- Staff login
- Enter student marks
- Manage marks for assigned subjects

### Student
- Student login
- View subject-wise marks
- View semester-wise performance
- View percentage
- View CGPA
- View pass/fail status
- View failed subjects
- View performance charts
- View leaderboard position

## 📊 Performance Analysis

The system provides meaningful academic insights using:

- Percentage calculation
- CGPA
- Pass/Fail analysis
- Subject-wise performance
- Semester-wise performance
- Performance charts
- Leaderboard

## 🛠️ Tech Stack

- **Backend:** Python, Django
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Database:** SQLite / SQL
- **Data Visualization:** Chart.js
- **Icons:** Remix Icon, Bootstrap Icons, Font Awesome

## ⚙️ How the System Works

1. User opens the application.
2. User selects the appropriate login according to their role.
3. The system authenticates the user.
4. Admin manages students, staff, subjects, and marks.
5. Staff enters and manages student marks.
6. Students view their academic performance.
7. The system generates performance analysis using tables and charts.
